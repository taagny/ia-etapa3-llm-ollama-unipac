```python
import re

def eh_palindromo(s):
    # Remove espaços, acentos e pontuação, e converte para minúsculas
    s = re.sub(r'[^a-zA-Z0-9]', '', s).lower()
    # Verifica se a string é igual ao seu inverso
    return s == s[::-1]

# Testes com assert
assert eh_palindromo("A man, a plan, a canal, Panama") == True

```

1. **Expressão Regular**: `re.sub(r'[^a-zA-Z0-9]', '', s)` remove todos os caracteres que não são letras ou números da string `s`.
2. **Conversão para Minúsculas**: `.lower()` garante que a comparação seja case-insensitive.
3. **Verificação de Palíndromo**: `s == s[::-1]` verifica se a string é igual ao seu inverso.
